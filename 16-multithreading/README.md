# 16 - Multithreading

Introduces running code concurrently using Java's Thread and Runnable.

## What this covers

- **Runnable** — defining a task to run on a thread
- **Thread** — starting and running that task concurrently
- **join()** — waiting for a thread to finish

## How to run

```bash
javac MultithreadingExample.java
java MultithreadingExample
```

Note: thread output order may vary between runs, since both threads run concurrently.
