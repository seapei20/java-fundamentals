# 14 - File I/O

Covers reading from and writing to files, using try-with-resources for safe cleanup.

## What this covers

- **FileWriter** — writing text to a file
- **BufferedReader / FileReader** — reading text from a file line by line
- **try-with-resources** — automatically closing file handles

## How to run

```bash
javac FileIoExample.java
java FileIoExample
```
