# 10 - Abstraction

Abstraction hides implementation details behind a simpler interface, using abstract classes and interfaces.

## What this covers

- **Abstract classes** — partial implementations that force subclasses to fill in the rest
- **Interfaces** — pure contracts with no implementation
- **Why it matters** — decoupling what something does from how it does it

## How to run

```bash
javac AbstractionExample.java
java AbstractionExample
```
