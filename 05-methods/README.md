# 05 - Methods

Methods let you group code into reusable, named blocks. This example covers defining methods, working with parameters and return values, and overloading.

## What this covers

- **Defining methods** — with and without parameters or return values
- **Parameters and return values** — passing data in, getting results out
- **Method overloading** — same name, different parameter lists
- **Calling methods from other methods** — building logic in layers

## How to run

```bash
javac MethodsExample.java
java MethodsExample
```
