# 15 - Lambdas & Streams

Introduces functional-style programming in Java using lambdas and the Stream API.

## What this covers

- **Functional interfaces** — interfaces with a single abstract method
- **Lambdas** — concise, inline implementations
- **Streams** — filtering, mapping, and collecting data declaratively

## How to run

```bash
javac LambdasStreamsExample.java
java LambdasStreamsExample
```
