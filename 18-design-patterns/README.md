# 18 - Design Patterns

Introduces three common design patterns and the problems they solve.

## What this covers

- **Singleton** — ensuring only one instance of a class exists
- **Factory** — creating objects without exposing instantiation logic
- **Observer** — notifying multiple listeners when something changes

## How to run

```bash
javac DesignPatternsExample.java
java DesignPatternsExample
```
