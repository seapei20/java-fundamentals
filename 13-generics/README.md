# 13 - Generics

Generics let you write classes and methods that work with any type, while keeping type safety at compile time.

## What this covers

- **Generic classes** — a reusable container type
- **Generic methods** — type parameters on a single method
- **Type safety** — catching type errors at compile time, not runtime

## How to run

```bash
javac GenericsExample.java
java GenericsExample
```
