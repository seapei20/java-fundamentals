# 04 - Arrays

Arrays let you store multiple values of the same type in a single variable. This example covers how to declare, loop over, and work with arrays.

## What this covers

- **Declaring arrays** — fixed-size collections of a single type
- **Standard for loop** — accessing elements by index
- **For-each loop** — a cleaner way to iterate when you don't need the index
- **Common operations** — sum, max, and length
- **Modifying elements** — arrays are mutable, unlike some other structures

## How to run

```bash
javac ArraysExample.java
java ArraysExample
```
