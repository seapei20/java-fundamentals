# 07 - Encapsulation

Encapsulation protects an object's internal state by keeping fields private and exposing controlled access through methods.

## What this covers

- **Private fields** — hiding internal state
- **Getters/setters** — controlled read/write access
- **Validation** — enforcing rules before changing state

## How to run

```bash
javac EncapsulationExample.java
java EncapsulationExample
```
