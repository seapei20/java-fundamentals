# 09 - Polymorphism

Polymorphism lets objects of different types be treated through a common parent type, with the correct method chosen at runtime.

## What this covers

- **Method overriding** — subclasses providing their own implementation
- **Dynamic dispatch** — the JVM picks the right method at runtime
- **Treating different types uniformly** — through a shared parent class

## How to run

```bash
javac PolymorphismExample.java
java PolymorphismExample
```
